# Планер целей и задач

Веб-версия MVP по документу «Планер целей и задач — описание приложения».
Месяц строится от 3–5 целей: цель → ключевые задачи → подзадачи → чек-пункты,
процент выполнения и темп считаются автоматически на уровне дня, недели и месяца.

## Как запустить

Откройте `index.html` в браузере (на телефоне или компьютере). Сервер не нужен.
Данные сохраняются в браузере; в опубликованной версии на claude.ai — в аккаунте.

`planner.html` — исходник страницы для публикации как Artifact (без `<html>`-обёртки),
`index.html` — тот же код в самостоятельной обёртке.

## Что сделано (MVP)

- Экраны: Месяц, Неделя, День, Цели (карточка цели с деревом и графиком), Аналитика,
  Ключевые события, Входящие; кнопка «+» на всех экранах.
- Цели двух типов («чек-лист» и «число»), веса 1–5, статусы задач.
- Расчёт процента снизу вверх по взвешенному среднему; отменённое не учитывается;
  задачи «Вне целей» входят только в процент дня.
- Темп: зелёный ≥ 90%, жёлтый 70–89%, красный < 70%; для числовых целей —
  сравнение с долей прошедших дней месяца.
- Перенос задач (флаг «Застряла» после третьего переноса), перетаскивание между днями
  на экране недели, перенос незавершённого на завтра.
- Нагрузка дня с лимитом часов, задачи-подготовка к событиям.
- Быстрый ввод одной строкой: «Созвон с клиентом пт 15:00 #продажи».
- Мастер нового месяца в 3 шага (сферы → цели → ключевые задачи по неделям).
- Тёмная тема по палитре из документа.

## Чего нет в веб-версии

Push-напоминания, виджет и офлайн-синхронизация между устройствами требуют
нативного приложения (Flutter + Supabase по рекомендации документа).
