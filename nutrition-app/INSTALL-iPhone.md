# Установка NutriAI на iPhone через MacBook

После установки NutriAI станет обычным приложением со своей иконкой на экране «Домой», без плашки Claude. В отличие от версии внутри Claude, здесь работают:
- живая камера и сканер штрихкодов;
- голосовой ввод;
- шагомер iPhone.

## Как это устроено

```
iPhone (приложение NutriAI)  ──►  ваш сервер NutriAI в интернете  ──►  Claude API (распознаёт еду)
```

Приложению нужен **сервер**: на нём хранится ваш ключ Claude API, поэтому ключ не попадает в телефон. Сервер мы бесплатно разместим на Render.com, чтобы он работал круглосуточно и MacBook можно было выключать.

> ⚠️ Данные из версии внутри Claude **не переносятся** в установленное приложение: оно хранит данные на самом iPhone. Анкету нужно будет заполнить заново.

## Что понадобится

| Что | Где взять | Стоимость |
|---|---|---|
| MacBook с актуальной macOS | — | — |
| Xcode (последняя версия) | App Store на Mac | бесплатно |
| Apple ID | тот же, что на iPhone | бесплатно (см. «Про 7 дней» в конце) |
| Кабель iPhone ↔ Mac | — | — |
| Аккаунт GitHub с этим репозиторием | у вас уже есть | бесплатно |
| Ключ Claude API | console.anthropic.com | оплата за использование, примерно 1–2 цента за одно распознавание |
| Аккаунт Render | render.com (вход через GitHub) | бесплатно |

---

## Шаг 1. Ключ Claude API

Подписка Claude (Pro/Max) и Claude API оплачиваются **отдельно**. Для приложения нужен ключ API.

1. Откройте **console.anthropic.com** и войдите.
2. **Billing** → пополните баланс. Для начала хватит $5–10.
3. **API Keys** → **Create Key** → назовите, например, `NutriAI` → скопируйте ключ (он начинается с `sk-ant-`).
   Сохраните его в «Заметках»: показать ключ повторно сайт не сможет.

## Шаг 2. Сервер на Render (≈5 минут)

1. Откройте **render.com** → **Get Started** → **Sign in with GitHub**.
2. **New +** → **Blueprint**.
3. Подключите репозиторий **yeahwoxic-afk/super-meme** и выберите ветку **`claude/ai-calorie-tracker-nutrition-45exka`**.
   Render сам найдёт файл `render.yaml` и предложит сервис **nutri-ai-api**.
4. Он попросит значение **ANTHROPIC_API_KEY**: вставьте ключ из шага 1 → **Apply**.
5. Подождите, пока статус станет **Live**. Откройте сервис и сохраните себе две вещи:
   - **адрес** вверху страницы, вида `https://nutri-ai-api-xxxx.onrender.com`;
   - **Environment** → значение **APP_API_TOKEN** (нажмите на глазик и скопируйте). Это пароль, по которому приложение обращается к серверу.
6. Проверка: откройте в браузере `ваш-адрес/health`. Должно показать `{"ok":true}`.

> Бесплатный сервер на Render «засыпает» после 15 минут без запросов. Первое распознавание после паузы может занять до минуты, дальше всё работает быстро. Чтобы сервер не засыпал, в Render выберите план **Starter** ($7 в месяц).

## Шаг 3. Подготовка MacBook (один раз)

1. Установите **Xcode** из App Store (≈10 ГБ, скачивается долго). Запустите его один раз и согласитесь с лицензией. Если Xcode предложит установить компоненты (iOS platform), согласитесь.
2. **Xcode → Settings → Accounts → «+» → Apple ID** → войдите своим Apple ID.
3. Откройте программу **Терминал** (Spotlight: ⌘ + пробел → «Терминал») и вставьте по очереди:

```bash
# Homebrew — установщик программ (попросит пароль от Mac; при вводе символы не видны, это нормально)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
В конце установки Homebrew покажет команды **Next steps** (`echo ... >> ~/.zprofile` и `eval ...`). Скопируйте их и выполните. Затем:

```bash
brew install node git cocoapods watchman
```

## Шаг 4. Скачать проект и указать адрес сервера

```bash
cd ~/Desktop
git clone https://github.com/yeahwoxic-afk/super-meme.git
cd super-meme
git checkout claude/ai-calorie-tracker-nutrition-45exka
cd nutrition-app/mobile
npm install
cp .env.example .env
open -e .env
```

Откроется файл `.env`. Впишите туда данные из шага 2 и сохраните (⌘S):

```
EXPO_PUBLIC_API_URL=https://nutri-ai-api-xxxx.onrender.com
EXPO_PUBLIC_API_TOKEN=токен-из-Render
```

**Уникальное имя приложения.** Откройте `app.json` (`open -e app.json`) и в строке `"bundleIdentifier": "com.nutriai.app"` замените `nutriai` на что-то своё, например `"com.ivanpetrov.nutriai"`. Бесплатный аккаунт Apple требует имя, которого больше ни у кого нет.

## Шаг 5. Подготовить iPhone

1. Подключите iPhone к Mac кабелем. На iPhone нажмите **«Доверять этому компьютеру»** и введите код.
2. На iPhone: **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включите → iPhone перезагрузится → подтвердите включение.
   (Если пункта нет, он появится после шага 6; тогда вернитесь сюда.)

## Шаг 6. Собрать и установить приложение

В Терминале (вы всё ещё в папке `nutrition-app/mobile`):

```bash
npx expo run:ios --device --configuration Release
```

- Выберите в списке **свой iPhone** (стрелками и Enter).
- Если спросит про команду разработчика (**development team**), выберите свой Apple ID (**Personal Team**).
- Первая сборка идёт 5–15 минут. Это нормально.

**Release** означает, что приложение собирается целиком и потом работает **без MacBook**.

Если сборка остановится с ошибкой **Signing / Provisioning**:
```bash
open ios/*.xcworkspace
```
В Xcode слева нажмите на проект **NutriAI** → вкладка **Signing & Capabilities** → **Team**: выберите свой Apple ID (Personal Team). Вернитесь в Терминал и повторите команду из шага 6.

## Шаг 7. Разрешить запуск на iPhone

При первом запуске iPhone скажет «Ненадёжный разработчик». Это обычное поведение для приложений, установленных не из App Store:

**Настройки → Основные → VPN и управление устройством → Apple Development: ваш@email → Доверять.**

Готово: на экране «Домой» появится иконка **NutriAI**. При первом использовании разрешите камеру, микрофон, распознавание речи и «Движение и фитнес» (для шагов).

## Про 7 дней (важно)

- **Бесплатный Apple ID:** приложение работает **7 дней**, потом iPhone перестаёт его открывать. Данные при этом **не пропадают**. Чтобы продлить ещё на 7 дней, подключите iPhone к Mac и повторите шаг 6 (папка та же):
  ```bash
  cd ~/Desktop/super-meme/nutrition-app/mobile && npx expo run:ios --device --configuration Release
  ```
- **Платный Apple Developer Program ($99 в год, developer.apple.com):** приложение работает год без переустановки. Можно также раздавать его через TestFlight себе и близким без кабеля.

## Как обновлять приложение, когда я внесу изменения

```bash
cd ~/Desktop/super-meme
git pull
cd nutrition-app/mobile
npm install
npx expo run:ios --device --configuration Release
```
Сервер на Render обновится сам после `git push` в эту ветку.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| «Нет связи с сервером» | Проверьте `ваш-адрес/health` в Safari. Если долго грузится, сервер просыпается: подождите минуту и повторите. |
| «Нет доступа к сервису» | Токен в `.env` не совпадает с APP_API_TOKEN в Render. Исправьте его и повторите шаг 6. |
| «Ошибка сервиса» | Render → сервис → **Logs**. Частая причина: закончились деньги на балансе Claude API (шаг 1). |
| `pod install` / CocoaPods error | `brew upgrade cocoapods`, затем повторите шаг 6. |
| «Xcode version too old» | Обновите Xcode и macOS через App Store. |
| Приложение не открывается через неделю | Это ограничение бесплатного Apple ID, см. «Про 7 дней». |

Сколько это стоит в месяц: Render бесплатно (или $7 без засыпания), Claude API около 1–2 центов за распознавание. Если распознавать 5 раз в день, выйдет примерно $2–3 в месяц. Дешевле можно с моделью Claude Sonnet: в Render → Environment поменяйте `AI_MODEL` на `claude-sonnet-5-5`.
