# NutriAI — подсчёт калорий и контроль питания с ИИ

Мобильное приложение (iOS / Android, Expo + React Native) и сервер с ИИ (Node.js + Claude API).

```
nutrition-app/
├── mobile/   # приложение Expo (React Native, TypeScript)
├── server/   # API: распознавание еды (Claude), штрихкоды (Open Food Facts), расчёт норм
└── shared/   # общая логика: нормы КБЖУ, порции, голодание, GLP-1 (используется и там, и там)
```

## Возможности

### ИИ-сканер еды
| Способ | Как работает |
|---|---|
| 📷 **Фото** | Снимок сжимается до 1024 px и отправляется на сервер, Claude находит каждую позицию на тарелке (гарнир, мясо, соус отдельно), оценивает вес порции и КБЖУ на 100 г. Умеет читать этикетки. |
| 🎙️ **Голос** | Речь распознаётся на устройстве (`expo-speech-recognition`, ru-RU), текст разбирается ИИ: «две котлеты и пюре» → продукты с граммовкой. |
| ▥ **Штрихкод** | Камера сканирует EAN/UPC, сервер берёт состав из открытой базы Open Food Facts. |
| ⌨️ **Текст** | Свободное описание приёма пищи. |

Перед сохранением результат можно проверить: изменить вес любой позиции (КБЖУ пересчитываются), удалить лишнее, выбрать приём пищи. Позиции, в которых ИИ не уверен, подсвечиваются.

Калории и суммы считает код, а не модель. ИИ возвращает только значения на 100 г и вес порции, а сервер проверяет, что калории сходятся с БЖУ по коэффициентам Этуотера (4/9/4), и исправляет их, если расхождение больше 25 %.

### Персональные цели
Формула Миффлина–Сан Жеора с учётом активности:
- **Снижение веса**: дефицит 20 %, белок 1,8 г/кг
- **Набор массы**: профицит 12 %, белок 1,8 г/кг
- **Поддержание формы**: калории равны расходу, белок 1,4 г/кг
- **Здоровое питание**: калории равны расходу, белок 1,2 г/кг, упор на клетчатку

Ограничения: калорийность не ниже 1200/1500 ккал. При ожирении белок считается от веса при ИМТ 25. Для тех, кто **принимает GLP-1**, белок не ниже 1,6 г/кг (чтобы сохранить мышцы), а дефицит не больше 25 %. Также рассчитываются нормы воды (33 мл/кг), шагов и клетчатки и примерный срок достижения целевого веса.
Все коэффициенты вынесены в `shared/config.ts`.

### Тренировки (вкладка «Спорт»)
- **Силовые**: тренажёры и свободные веса, тяжёлая база, круговая/кроссфит, свой вес, гири, пилатес, йога, растяжка.
- **Кардио**: ходьба, бег 8/10/12 км/ч, велосипед, эллипс, гребля, степпер, плавание, HIIT, скакалка, танцы, игровые виды спорта.
- **Своя**: калории, уже посчитанные часами или фитнес-браслетом.
- Сожжённое считается по таблицам MET (Compendium of Physical Activities) с учётом веса, длительности и интенсивности. Учитываются только калории сверх обмена в покое: `(MET·k − 1) · 3,5 · вес / 200 · минуты`.
- Эти калории **прибавляются к дневной норме** в дневнике (норма + тренировки − съедено). Если тренировки записываются в приложении, уровень активности в профиле лучше ставить «Сидячий», чтобы не учитывать их дважды.
- Каталог и коэффициенты лежат в `shared/workouts.ts`.

### Трекеры привычек
- 💧 **Вода**: кнопки +150/+250/+500 мл, кольцо прогресса до дневной нормы.
- 👟 **Шаги**: с датчика телефона (на iOS — история за день, на Android — шаги, пока приложение открыто) или вручную.
- ⚖️ **Вес**: журнал взвешиваний, изменение с начала. Последний вес обновляет нормы.
- ⏱️ **Интервальное голодание**: 12:12, 14:10, **16:8**, 18:6, 20:4, OMAD. Таймер, прогресс, стадия, время открытия окна питания.
- 💉 **GLP-1**: Оземпик/Вегови, Рибелсас, Мунджаро/Зепбаунд, Саксенда/Виктоза, Трулисити. Журнал доз, напоминание о следующей дозе (раз в неделю или ежедневно), ротация мест инъекции, заметки о самочувствии.

Данные хранятся на устройстве (AsyncStorage). Сервер ничего не хранит, а ключ Anthropic есть только на сервере.

## Открыть без установки (в Claude)

Приложение опубликовано как страница в Claude: https://claude.ai/artifact/UH5QKS6SZMzoCKje8WeKXv
Ссылка открывается в приложении Claude на телефоне или в браузере, сервер для этого не нужен:
- еду распознаёт Claude через аккаунт того, кто открыл страницу (при первом распознавании Claude спросит разрешение);
- данные хранятся в личной папке этого пользователя, поэтому они одинаковы на всех его устройствах;
- голосовой ввод работает через кнопку микрофона на клавиатуре, а вместо штрихкода фотографируется этикетка, потому что внутри Claude у страницы нет доступа к микрофону и интернету.

Пересобрать страницу: `cd mobile && node scripts/build-artifact.mjs` (результат будет в `mobile/dist-artifact/nutri-ai.html`).

## Запуск

### Сервер
```bash
cd nutrition-app/server
npm install
export ANTHROPIC_API_KEY=sk-ant-...      # ключ Claude API
npm start                                # http://localhost:8787
# без ключа, с тестовыми ответами:  npm run demo
```

Переменные окружения:
| Переменная | По умолчанию | Назначение |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ Claude API |
| `AI_MODEL` | `claude-opus-5-5` | модель распознавания (можно указать `claude-sonnet-5-5` или `claude-haiku-5-5`, чтобы было дешевле) |
| `AI_EFFORT` | `low` | глубина рассуждений: `low`, `medium` или `high` |
| `APP_API_TOKEN` | — | если задан, приложение должно присылать `Authorization: Bearer <token>` |
| `PORT` | `8787` | порт |

Включён серверный fallback Claude API (`fallbacks: "default"`): если модель отклонит запрос по правилам безопасности, API сам повторит его на подходящей модели. Отключается в `server/src/ai.ts`.

API:
- `POST /api/recognize/photo`: `{ imageBase64, mediaType?, hint? }` → `{ items, totals, note }`
- `POST /api/recognize/text`: `{ text }` → то же
- `GET  /api/barcode/:code` → продукт с КБЖУ
- `POST /api/targets`: профиль → дневные нормы
- `GET  /health`

### Приложение
```bash
cd nutrition-app/mobile
npm install
EXPO_PUBLIC_API_URL=http://<IP-компьютера>:8787 npx expo start
```
Камера, сканер штрихкодов и шагомер работают в Expo Go. **Голосовой ввод** использует нативный модуль, поэтому для него нужна dev-сборка (`npx expo run:ios` / `npx expo run:android` или `eas build --profile development`). В Expo Go можно диктовать кнопкой микрофона на клавиатуре.
